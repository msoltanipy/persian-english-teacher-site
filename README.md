# وب‌سایت شخصی آموزش زبان انگلیسی (Django + Docker Compose)

یک وب‌سایت مدرن، تمام‌فارسی (RTL) و یکپارچه با **Django** (فرانت‌اند و بک‌اند در یک اپلیکیشن واحد `academy`) برای مدرس زبان انگلیسی، شامل:

- **صفحه اصلی مدرن** با معرفی مدرس، جزوات برگزیده و جدیدترین مقالات
- **پروفایل مدرس (`/profile/`)** شامل بیوگرافی، فلسفه تدریس، مدارک، حوزه‌های تخصصی و راه‌های ارتباطی
- **بخش مقالات و آموزش‌ها (`/posts/`)** با دسته‌بندی، جستجو و کادرهای چپ‌به‌راست (LTR) برای مثال‌های انگلیسی
- **فروشگاه جزوات و کتابچه‌ها (`/booklets/`)** با فیلتر نوع منبع (جزوه / کتابچه) و سطح، و دکمه **سفارش مستقیم در تلگرام** با پیام فارسی آماده به آیدی `@inatlosm`
- **بخش تماس با من (`/contact/`)** با فرم ثبت پیام در دیتابیس (قابل مشاهده در پنل مدیریت) + دکمه پیام سریع در تلگرام
- **پنل مدیریت فارسی جنگو (`/admin/`)** برای ویرایش کامل پروفایل، افزودن مقاله، افزودن جزوه/کتابچه و بررسی پیام‌های تماس

## اجرای سریع با Docker Compose

1. فایل زیپ را استخراج کرده و وارد پوشه پروژه شوید:
   ```bash
   cd english_teacher_site
   ```
2. (اختیاری) فایل `.env.example` را به `.env` کپی کرده و رمزها را تغییر دهید.
3. دستور زیر را اجرا کنید:
   ```bash
   docker compose up --build
   ```
4. وب‌سایت روی آدرس زیر در دسترس خواهد بود:
   - صفحه اصلی: `http://localhost:8000`
   - پنل مدیریت: `http://localhost:8000/admin`

### اطلاعات ورود پیش‌فرض پنل مدیریت
- **نام کاربری:** `admin`
- **رمز عبور:** `ChangeMe1234!`
*(پیشنهاد می‌شود قبل از انتشار روی سرور، مقادیر `DJANGO_SECRET_KEY`، `DJANGO_DEBUG=False` و `DJANGO_SUPERUSER_PASSWORD` را در فایل `.env` تغییر دهید.)*

## ساختار پروژه (تک‌اپلیکیشن Django)
- `config/` — تنظیمات اصلی پروژه جنگو (`settings.py`, `urls.py`, `wsgi.py`)
- `academy/` — اپلیکیشن واحد شامل مدل‌ها، ویوها، فرم‌ها، پنل ادمین، قالب‌های HTML، فایل‌های استاتیک (CSS/JS) و دستور `seed_initial_data`
- `Dockerfile` و `docker-compose.yml` — اجرای یکپارچه Django (Gunicorn + WhiteNoise) همراه با PostgreSQL 16
